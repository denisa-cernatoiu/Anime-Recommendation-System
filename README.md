# [Anime Recommendation System](https://anime-recommendation-system-rxng.onrender.com/)
An interactive website where the user can get suggestions on what to watch next based on it's preferences.

## Technologies:
- Flask
- Bootstrap
- HTMX
- TF-IDF
- Lemmanization
- Cosine Similarity

## Features:
- user can select it's favorite anime and will recieve content based recommendations;
- database recommendations based on input typed;
- the recommendation cards reveal on mouse hoover one face the anime banner and on the other side it's rating and description;
- hosted on Render
